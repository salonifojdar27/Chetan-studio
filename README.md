# 📸 Chetan Studio – Photography Website.

>A modern, elegant, and fully responsive photography portfolio website built for Chetan Studio.
>This website showcases high-quality visuals, smooth animations, and a premium user experience using React, Tailwind CSS, and Framer Motion.

---

## 🔥 Features

- **Fully responsive design**
- **Smooth animations using Framer Motion**
- **Fast performance with React + Vite**
- **Modern UI with Tailwind CSS**
- **Dedicated pages: Home, About, Gallery, Stories, Contact**
- **Clean folder structure**
- **Easy to customize images and content**

---

## 🧑‍💻 Tech Stack

- **React JS**
- **Tailwind CSS**
- **Framer Motion**
- **React Router DOM**
- **Vite**

## 🛠️ Installation & Setup

### 1. 📥 Clone the Repository

```bash
git clone https://github.com/your-username/your-repository-name.git
cd ChetanStudio
```

### 2.📦 Install Dependencies

```bash
npm install
```

### 3. 🚀 Run the Development Server

```bash
npm run dev
```
